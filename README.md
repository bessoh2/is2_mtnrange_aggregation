# is2_mtnrange_aggregation
Evaluation of large-scale aggregation of ICESat-2 data for median snow depth estimates. 

Order to run notebooks in:
* sliderule_data_access.ipynb
* process_sliderule_data.ipynb
* site_figures.ipynb
* analysis_figures.ipynb
Although the order of the figure-making notebooks does not matter.

Note that this analysis was completed with version 006 of ICESat-2 data. Different results may result from using different versions of data. To access version 006 data with the newest version of Sliderule Earth (v5.4.5), see the code in sliderule_data_access.ipynb, which specifies individual granule names to enable version 006 access.
